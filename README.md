# E-COMMERECE-SQL-Project
Designed and deployed an Online Food Delivery SQL project with 5 relational tables, ER diagram, and analytical queries to uncover customer behavior, top items, city‑wise revenue, and spending trends, supported by visualizations for actionable business insights and decision‑making.


# 🍽️ Online Food Delivery SQL Project
Domain: E-Commerce
Tools Used: SQL, ER Diagrams, Data Visualization
Dataset Size: ~800 rows across 5 relational tables

## 📌 Objective
To perform in-depth analysis on a real-world food delivery dataset using SQL, uncovering trends in customer behavior, restaurant performance, and item popularity through structured queries and visualizations.

## 📂 Dataset Description

| Table Name      | Description |
|-----------------|-------------|
| customer_table  | Customer details: ID, name, email, city, signup date |
| menu_item       | Menu items: item ID, restaurant ID, name, price |
| order_details   | Items per order: order detail ID, order ID, item ID, quantity |
| orders          | Order-level info: order ID, customer ID, restaurant ID, order date |
| restaurant      | Restaurant info: ID, name, city, registration date |
